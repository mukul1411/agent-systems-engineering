# agent-systems-engineering

It’s a single self-contained html file. 

agent-systems-engineering.html. 

How it’s organised:

Five control surfaces. Prompt, context, harness, loop and graph sit at the top as a nested stack diagram.
Eleven modules follow from the stack. They are a prompt and specification module plus the ten topics in your screenshots. Each module has:
theory
a worked example
open-source and paid tools
failure modes
three practice questions with model answers, collapsible, with a “Show answers” toggle
Eight-phase lifecycle. It runs from deciding whether you need an agent at all through to operations. Every phase produces an artifact a reviewer can challenge.
One running case across all modules: Ledgerline, a fictional agent that resolves invoice exceptions. I picked it because it has every hard problem at once: private data, untrusted supplier emails and money movement.
Capstone. A health-insurance claims brief with a weighted grading rubric and a ten-week teaching plan.
